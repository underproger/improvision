# improvision на MODX 3

Готовый сайт на **MODX Revolution 3.1.2** с тремя языками (UA, EN, RU) и всем контентом из вёрстки.

```
modx/
  site/              корень сайта — это заливается на хостинг
  improvision.sql    дамп базы данных
  _dev/              скрипты, которыми сайт собран из вёрстки (на хостинг не нужны)
```

Дополнения: **pdoTools 3** (Fenom), **MIGX 3**, **Babel 3**.

## Требования

- PHP **8.1+** (pdo_mysql, gd, zip, curl, mbstring, dom, fileinfo)
- MySQL 5.7+ / MariaDB 10.3+, кодировка `utf8mb4`
- Apache с `mod_rewrite` (`.htaccess` уже в `site/`) или nginx (правила ниже)

## Установка на хостинг

1. Залить содержимое `site/` в корень сайта (`public_html` и т. п.).
2. Создать базу (`utf8mb4_unicode_ci`) и импортировать `improvision.sql`.
3. В `site/core/config/config.inc.php` вписать доступ к БД: `DB_NAME`, `DB_USER`, `DB_PASSWORD`
   (и `$database_server`, если не `localhost`). Пути и домен определяются сами — больше ничего менять не нужно.
4. Права на запись: `core/cache/`, `core/export/`, `assets/img/` (загрузка картинок).
5. Зайти в `/manager/` (логин `admin`, пароль передан отдельно) → сменить пароль →
   «Управление → Очистить кэш».
6. Почта для заявок: «Системные настройки» → пространство имён `improvision` → `improvision.lead_email`
   (можно несколько через запятую). Письма уходят через PHP `mail()`; если хостинг их не отправляет —
   включить SMTP в системных настройках (`mail_use_smtp`, `mail_smtp_hosts`, `mail_smtp_user`, …).
   Копия каждой заявки пишется в `core/export/improvision-leads/ГГГГ-ММ.log`.
7. Рекомендую поставить через «Установщик» визуальный редактор **TinyMCE Rich Text Editor** —
   без него поля «Вміст» редактируются как HTML.

nginx:

```nginx
location / {
    try_files $uri $uri/ @modx;
}
location @modx {
    rewrite ^/(.*)$ /index.php?q=$1&$args last;
}
location ~ ^/core/ { deny all; }
```

## Как устроено

### Языки

- Контексты: **web** — украинский (`/`), **en** — `/en/`, **ru** — `/ru/`. Префиксы обрабатывает плагин `impRouter`.
- Переводы связаны Babel: в редактировании ресурса вверху — переключатель языков, оттуда же «Создать перевод».
  Картинки, категории, флаги и т. п. Babel копирует в переводы сам (`babel.syncTvs`), тексты — нет.
- Тексты интерфейса (кнопки, подписи, aria-метки, названия категорий) — словарь:
  «Настройки → Словари» → пространство имён `improvision`, тема `default`, язык `uk` / `en` / `ru`.

### Страницы и шаблоны

| Шаблон | Ресурсы | Что редактируется |
|---|---|---|
| Головна | Главная | H1, фото (3 размера), преимущества, тексты блоков |
| Про нас | Про нас | H1, фото, вступление, «Шлях компанії», команда |
| Послуга | дочерние «Послуги» | H1, анонс, фото, текст в 3 частях, чек-лист, выноска, этапы, вкладки, проекты |
| Проєкти / Проєкт | «Проєкти» и дочерние | категория (фильтр), карточка, галерея, характеристики, направления |
| Блог / Стаття | «Блог» и дочерние | рубрика, теги, фото, «в слайдере», краткое описание, время чтения |
| Контакти | Контакти | карточки контактов, выезд, отделы, карта |
| Текстова сторінка | политика, условия, 404, новости, вакансии | обычный текст |
| Загальні блоки | «Загальні блоки» (не опубликован) | телефон, email, адрес, соцсети, бренды, этапы, «Чому ми», цифры, блок заявки |

- Поля сгруппированы по вкладкам: SEO, Зображення, Картка та фільтр, Списки MIGX, Тексти та блоки, Контакти.
- В многострочных полях новая строка = перенос строки в заголовке.
- Верхнее меню — опубликованные ресурсы верхнего уровня без галочки «Не показывать в меню»;
  «Компанія» в подвале — все опубликованные ресурсы верхнего уровня, кроме служебных.
- **«Новини» и «Вакансії» созданы неопубликованными** (контента нет) — опубликуйте, когда будет.
- «Послуги» — ссылка на блок услуг главной; порядок карточек на главной — поле «Порядок на головній».
- Форма заявки отправляется на ресурс «Заявка» (`/lead.json`, сниппет `impLead`), от ботов — скрытое поле.
- `sitemap.xml` (все языки) и `robots.txt` уже есть.

### Код

Шаблоны, чанки, сниппеты и плагин — статичные элементы, файлы лежат в
`site/core/components/improvision/elements/`. Их можно править и в менеджере, и в файлах;
после правки файла по FTP — очистить кэш. Шаблоны на Fenom (pdoTools), базовый макет — шаблон `Base`.

CSS/JS — те же, что в вёрстке (`assets/css/main.css`, `assets/js/main.js`).
После правок SCSS/JS в корне репозитория: `npm run modx:assets` — копирует сборку в `modx/site/assets/`.

### Отличия от вёрстки

- Адреса без `.html`: `/about/`, `/services/facades/`, `/projects/kfc-artmall/`, `/blog/turnkey-store/`, `/contacts/`.
- Тексты, которых в макете не было: политика конфиденциальности и условия использования (черновик —
  стоит показать юристу), страница 404, тексты статей 2–4 блога.
- У проектов, кроме KFC, есть только карточка и характеристики (заказчик, город, год) — описание и галерею
  нужно добавить из реальных материалов.

## Пересборка из вёрстки (_dev)

Нужны только для разработки: ставят настройки, контексты, TV и элементы (`setup.php`), вытаскивают
контент из собранной статики (`extract.py` → `data.json`) и загружают его (`import.php`).
**`import.php` удаляет все ресурсы и создаёт их заново** — на живом сайте не запускать.
